# Boomer Automation — Website Template Library

A standalone gallery of landing-page concepts. The gallery uses Boomer Automation's name and lion mark, while the templates themselves deliberately explore independent visual directions.

## Current milestone

Template 01 — **Quiet SaaS** — is live and linked from the gallery.

Open `index.html` with Live Server, then click the Quiet SaaS thumbnail or **View template** link.

## Structure

- `index.html` — main template gallery
- `styles.css` — gallery styles
- `script.js` — gallery filtering
- `templates/quiet-saas/index.html` — Template 01
- `templates/quiet-saas/styles.css` — Template 01 styles
- `templates/quiet-saas/script.js` — Template 01 mobile navigation
- `PROJECT-ROADMAP.md` — project status


## Thumbnail sync
Template 01 uses a gallery preview rebuilt to mirror the live Arc template: same wordmark, near-white/green palette, hero typography, CTA treatment, and dashboard composition.
