# David — asset preparation
Original sculpture: Michelangelo Buonarroti, David (1501–1504).
Digital model: Scan the World @ MyMiniFactory / Scan the World.
Source: https://commons.wikimedia.org/wiki/File:David_(Michelangelo).stl
Original file: https://upload.wikimedia.org/wikipedia/commons/4/4d/David_%28Michelangelo%29.stl

The source is a scan-based 3D printable model, not Stanford's restricted research archive. The prepared derivative will be simplified, reoriented, normalized and repacked for web delivery. Those derivative mesh files remain CC BY-SA 4.0. No endorsement is implied. The application code is separate from the model.
Optimized derivative: 18,000 triangles, 8,966 vertices; reoriented and normalized, normals quantized for the web. Review variant ?sculpture=david uses the derivative unchanged in shape with a rotated placement, plinth and separate marble shading. The default gallery remains unchanged pending review. Attribution is displayed in the variant.
