# SHIFT storyboard assets
All HTML, CSS and SVG artwork created for this fictional demonstration. No external assets, fonts, financial network logos, existing brand artwork or real card details. The card is an original vector illustration transformed using CSS for static composition; not yet a live 3D model. No information collected. Draft deliberately excluded from catalogue discovery by the _drafts parent. P2 will replace the static artwork with an original procedural mesh while retaining static fallback.

P2 model.html and scene.js implement original closed rounded rectangular mesh, actual face/bevel/edge triangles and two locally generated Canvas2D printed surface textures, with procedural WebGL lighting. No third-party models or graphics assets. The storyboard retains its illustrated artwork pending P3 integration.

P3 uses the same original 3D model and texture generation in the full page. Motion is native scroll driven. Static SVG remains available for no JS, reduced motion, context loss and manual still view.

P4 adds locally generated graphite and silver static SVG counterparts and shared original material definitions. The WebGL shader receives independent edge/specular/roughness values and updates both texture faces without replacing the mesh. Finish choices work in the static/reduced-motion view as well. No external assets or financial service.
