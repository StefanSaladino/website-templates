# MONOLITH — architectural project index

A minimalist, image-first *contact sheet* with a distinctive top photo composition, linked index and four independent project plates. Plain HTML/CSS/JS — no build step.

## Edit the site

1. In `index.html`, change the business name/intro and four project names, years, locations and captions.
2. Update both the hero contact sheet and the matching main project photographs. Each photograph is a non-interactive figure, and the numbered hero links lead to `#north-house`, `#the-fold`, `#court-house` and `#limestone-house`. Update the anchor IDs if you change these names.
3. At the top of `styles.css`, adjust `--paper`, `--ink` and `--accent`.
4. Replace `hello@example.com` with the business inbox in the contact link.
5. Supply licensed photography, use local optimized responsive assets, and update alt text and credits. Remote Unsplash samples **are not bundled in the ZIP**.
6. Update title/description, favicon, social image (`og-card.jpg`), and your deployed **absolute** `og:image` URL.

## Interaction notes

The mobile menu traps keyboard focus within itself and makes the covered page inert until closed; Escape restores the menu button's focus. The architectural images do not falsely promise separate project pages. No forms or backend are present.

All business/project details are fictional demonstration content.
