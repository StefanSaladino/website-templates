# Landing Page Lab — Step 1

Standalone gallery foundation for the landing-page template project.

## Included in this handoff

- Main gallery page
- Responsive desktop / tablet / mobile layout
- Working category filters
- Ten visually distinct placeholder concepts
- Accessibility basics (skip link, semantic structure, pressed filter states, reduced-motion support)
- No links to unfinished template pages yet
- No framework or build step required

## Run locally

The simplest option is to open `index.html` directly in a browser.

For a local HTTP server, from this folder run either:

```bash
python -m http.server 8000
```

or

```bash
npx serve .
```

Then open `http://localhost:8000`.
