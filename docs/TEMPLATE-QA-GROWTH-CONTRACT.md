# Template growth contract
Source of truth: valid folders under `templates/`, each with index.html (shared asset directories use a leading underscore). Compare the discovered set with unique gallery routes and built files, not a fixed number. A new website must have a Preview thumbnail, accessible main/skip, responsive layout and provenance. Source accessibility, gallery, touch, reflow, all-site baseline and build checks automatically include it. Existing focused menu/modal/form checks are not removed. External-stock media require publisher attribution, exact active inventory/queue coverage and a loaded-media batch entry. Batch names drive the CI matrix. For an immersive site declare `data-immersive-template` and supply an interaction/fallback spec in `components/data/immersive-tests.json`; actual pixel changes, static fallback and no-JS are tested on current source. Add extra focused checks where the experience needs them, especially touch gestures, context loss and scroll. Category plannedCount is authoritative for components, not the previous total. Automated passing does not authorize production, certify accessibility or grant stock rights.

The manual photo-candidate acquisition workflow now selects current active media by the requested template slug and limit, verifies report membership against the manifest, and never refers to retired IDs or automatically downloads stock when workflow code changes. Still capture now checks all video posters and blocks all media requests. Source syntax validation parses referenced executable inline and linked scripts, including ES modules, and verifies local script paths. Existing asset-specific regression assertions remain intentional and are updated only when those assets change.
