## Build 2 — ABYSS / shader programming
An editorial underwater descent with distinct scientific/narrative chapters. Primary demonstration is original GPU fragment shaders, not imported models. Define depth-dependent absorption and scattering, procedural wave interference and caustics, suspended particulates, light shafts and original stylized bioluminescent organisms. Use a bounded raymarch or layered analytical shader where suitable, with mobile quality tiers and deterministic shader parameters. Native scroll or explicit chapter buttons change depth; no forced scroll or audio. Optional manual pause and reduced-motion still state. Semantic content and SVG still fallback. Tests must prove actual pixels respond to depth, time/motion pause and quality settings, shaders compile, reverse state remains coherent, context loss and no-GPU fallback work. Record performance and visual evidence. Do not pretend full ocean physics. Planned only.

## Build 3 — ORBIT / programmatic cinematic sequences
A continuous surface-to-orbit story for a fictional aerospace studio. Primary demonstration is choreography: authored camera keyframes, easing, timeline interpolation, chapter-synchronized typography, spatial transitions, lighting and original procedural planet/terrain/craft silhouettes. No prerecorded film. Scene order: surface, departure, atmospheric transition, orbital reveal, final horizon. Real scroll drives deterministic reversible progress; explicit previous/next or chapter links provide equivalent navigation. Manual replay optional, no scroll hijack, no mandatory loading screen. Mobile alternate choreography, reduced-motion chapter stills and full HTML content. Tests: forward/backward scroll, jump to chapters, replay/cancel, no-GPU/no-JS, resizing, reduced motion, no offscreen rendering, actual visible pixel changes and performance. Planned only.
