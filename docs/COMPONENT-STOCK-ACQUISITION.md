# Stock candidate acquisition workflow
The workflow `.github/workflows/component-stock-review.yml` runs only in the `feature/component-showroom` development branch when its dedicated script or workflow changes. It tries to download image candidates from **images.unsplash.com** and publishes the results as a temporary GitHub Actions artifact (with a contact sheet and SHA-256 acquisition report), with no write permissions and no change to `main`.

This is a **visual-review step only**. The output files are provider-served JPEG copies, not certified original files, and their presence does not establish third-party model/property permissions. The registered nine photo entries remain `needs-review`. After inspecting the contact sheet and obtaining any necessary permissions, select appropriate local derivatives to commit using the optimizer, with source/hashes documented, then verify all live crops and create real thumbnails. Do not mark stock assets approved solely because the action succeeds.
