# FOLD — independent paper-engineering study

## Direction reset
Stakeholder rejected SELVEDGE after gallery registration: too similar to SHIFT's pinned moving product composition, jacket photograph unsuitable, inadequate variety of animation and genuine 3D. Do not reuse either product/story track. SELVEDGE remains an existing gallery-only review record, visually rejected, pending removal/replacement decision; no customer configurator availability. No main merge.

FOLD is a different fictional design-studio concept: dimensional typography on a real mathematical connected strip of eight hinged CSS 3D planes. No generated imagery, stock photography, fake product or existing brand. The printed artwork is native text and a simple geometric mark, not a synthetic photograph. The surface changes shape via actual hinge geometry, rather than a rotating card, camera-only orbit or scroll-following image. The page uses ordinary scrolling with no pinned stage. Opening features oversized type, warm paper and indigo workbench. Explicit fold/unfold and a continuous range, optional horizontal drag; preserve vertical touch scroll. Flat HTML artwork remains for no JS/forced colours; reduced motion snaps instead of animating.

## Phases
- F1: independent functional draft, original print composition and connected 3D geometry; numerical crease continuity, desktop/phone actual browser captures, keyboard and no script. **Implemented, not yet visually or physically verified.**
- F2: inspect actual opening, folded, intermediate and flat captures; correct readability, depth, shading and edge alignment. Record actual motion and reversal performance. Validate touch, Safari and real devices; no arbitrary frame claims.
- F3: add a genuinely different secondary interaction if it strengthens the studio: sequential crease diagram / print registration layers, not more floating product spins. Natural page flow.
- F4: visual direction approval before catalogue registration; exact opening screenshot; standalone and actual configurator preview only after respective gates. No automatic gallery addition.
